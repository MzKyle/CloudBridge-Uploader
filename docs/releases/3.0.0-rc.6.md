CloudBridge Uploader `3.0.0-rc.6` adds Windows runtime acceptance and fixes path handling.

- Fix truncated file and directory names when a source root ends with a separator.
- Preserve Windows drive/share roots and use native containment checks.
- Use the packaged application tray icon and the correct Windows app identity.
- Show the actual log directory in startup errors.
- Add a packaged Windows smoke gate to the release workflow.

Windows validation on 2026-10-05: 108 automated tests; native NSIS install, launch
and uninstall; encrypted test credentials; multi-root scanning; single-part and
multipart S3 uploads; isolated destination retry; abrupt-upload restart recovery;
task rule snapshots; group sealing; history and single-instance window recovery.

Upload smoke uses a local S3 protocol fixture. Real cloud endpoint acceptance is
still required for the user's configuration. This is a release candidate, and
Windows installers remain unsigned.

Downloads: Windows x64 NSIS `.exe`, Linux x64 AppImage and `.deb`, plus
`SHA256SUMS.txt`. Updates are installed manually.
