# Legacy / v2 Remote Transfer

This page is retained only as historical context for older planning and compatibility notes.

CloudBridge Uploader v3.0.0-rc.1 does not publish SSH, rsync, or SFTP remote transfer as
part of the current release model. The v3 release model is local Source Roots configured
through UploadRule and uploaded to CloudConnection destinations.

Future remote-source work should be planned as a v3.1 feature and must not change the v3
RC runtime model.
